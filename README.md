Pixel Pet is a handheld ESP32-S3-based device that brings back the virtual pet experience, built entirely from scratch, including custom PCB, 3D printed enclosure, and original C++ firmware.

The board features a 4-layer custom PCB design (ESP32-S3-WROOM-1, ST7789 TFT display, BMI323 IMU, LiPo charging with power path management, and tactile button input), fabricated and assembled through JLCPCB. The enclosure is designed in Fusion 360 and 3D printed to house the board, display, and battery in a compact handheld form factor.

This project was built as a hands-on portfolio piece to demonstrate end-to-end embedded systems and PCB design skills across schematic capture, layout, firmware development, and mechanical design.
